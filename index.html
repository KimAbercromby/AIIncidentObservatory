Remediation picture

Incident databases record harms. Almost nothing records what was done afterwards, so "no remediation recorded" is expected to be the biggest category. That is a gap in the discipline, not in this tool. For incidents, remediation is indicated by wording in the description and is unverified. For curated cases, it is documented with sources.

Curated public-sector cases

Well-documented cases where a court, regulator or inquiry made a finding, or the deployer withdrew the system. Every fact has a source. The determination badge shows the highest level actually reached.

Incidents

Every AI Incident Database record is an allegation unless an authority made a finding. Chips show matched failure modes; a dashed chip is a machine suggestion. Green chips are remediation indicated by the text.

Run log

Every weekly run is logged, including runs that found nothing new. That is the record that monitoring actually happened.
